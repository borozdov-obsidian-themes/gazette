# Borozdov Gazette

A theme from the Borozdov collection. Two faces — light **Morning**, a quality broadsheet
on cream newsprint, and dark **Evening**, the late edition. Serif columns, hairline rules,
square corners and one signal yellow.

![Borozdov Gazette in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/gazette/main/screenshots/light.png)

![Borozdov Gazette in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/gazette/main/screenshots/dark.png)

## Principles

- **Print, not screen.** Cream newsprint, grey panels and hairline rules; square corners
  everywhere, a soft edge only on photographs.
- **One colour.** Signal yellow fills only what you act on — checked tasks, toggles, the
  main button, the highlighter — and links stay ink with an underline.
- **Serif columns.** The page is set in Libertinus Serif; headlines keep the regular
  weight and are tracked tight, like a masthead.
- **Eyebrows.** Tags, table headers, callout titles, folders, tabs and the status bar are
  tracked capitals in the system sans, the way a broadsheet labels its sections.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as boxed items: a grey panel with a rule on top in the type's colour
- Pull quotes in italic serif behind a black rule; a black column rule for `---`
- Code on a white card with hairlines; tables as a print grid with eyebrow headers
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Gazette**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/gazette/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Gazette/`, then choose Borozdov Gazette under
Settings → Appearance → Themes.

## Font

Libertinus Serif (© 2012–2024 The Libertinus Project Authors) is embedded in `theme.css`
as base64 WOFF2 under the SIL Open Font License 1.1 — see [`fonts/OFL.txt`](fonts/OFL.txt).
Only the regular weight, Latin and Cyrillic, to stay under the directory's size limit;
bold text is synthesized by the renderer.
